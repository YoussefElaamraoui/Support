# CarePals (Support)

A Flutter caregiver support app scaffold with:

- Bottom navigation across Home, Physical Support, Online Support, and Profile screens
- Drift + SQLite local storage setup for offline-first mood tracking data
- Basic widget tests for navigation and dashboard presence

## Run locally

1. Install Flutter SDK
2. From repository root:
   - `flutter pub get`
   - `flutter run`
   - `flutter test`
